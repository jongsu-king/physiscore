Physiscore 3.1.2 fixes the problems that showing every window with data loaded brought to
light, and adds screenshots of all windows to the README and the user guide.

### Fixed - analysis
- **PL single-band FWHM on weak, noisy bands.** The fit window was cut at "valleys" that
  were only noise dips beside the maximum, so on a band with a peak-to-noise ratio of
  about 15-40 the FWHM came out 2-4 times too small for some noise draws. A valley now
  has to be deeper than 2 % of the peak and than six noise standard deviations, the noise
  being measured inside the band. On a 90 meV band with the default baseline, 40 noise
  draws at a peak-to-noise ratio of 42 now give 80.8-83.0 meV (before: 21-91 meV); the
  remaining offset from 90 meV is the ALS baseline bending under the band, which a stiffer
  baseline removes (see the user guide). Clean spectra and the validation table are
  unchanged.
- **XPS auto-fit next to large peaks.** A small peak beside a large one (for example a
  metallic Pb 4f shoulder) either lost its component to the large peak or got zero
  amplitude. Overlapping singlet candidates are now fitted together, and each component
  stays near the peak it was seeded from. On a Pb 4f example the 4f5/2 : 4f7/2 area ratio
  is 0.747 (true 0.75) and the metallic fraction 0.097 (true 0.095).

### Fixed - windows
- **FE-SEM**: after segmentation the statistics, the histogram, the Excel export and the
  report failed (a module was not imported). The table headers were white on white.
- **Raman and FTIR**: section titles and the peak-detail panel were white on white. The
  FTIR axis is now labelled by what is plotted (band depth below the baseline, or
  absorbance).
- **PL**: the results table pushed the plot out of a 1440-pixel-wide window; the table now
  has a fixed width and scrolls sideways.
- **EQE**: axis labels and titles of the four plots overlapped.
- **J-V dark**: a missing instrument shunt resistance was shown as "non Ω"; it now reads
  "not in file". The automatic y range snaps to whole decades.
- **Device summary**: the unit and origin columns of the summary table were cut off.
- **Auto-fit workspaces**: axes are labelled per technique (2θ, wavelength, binding
  energy); XPS is drawn with the binding energy decreasing to the right.
- **Segmented buttons** in every window: the selected segment has white text and the
  others the normal text colour (one of the two was unreadable before).

### Added
- Screenshots of all windows (`docs/images/`), made with `tools/screenshots.py`, which
  now captures each window alone with synthetic example data.
- Tests: weak-band PL width over 20 noise draws, the XPS cluster fit, the FE-SEM core
  module binding, and a static check for undefined names in every module (run in CI).
  263 tests in total.
