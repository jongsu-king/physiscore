Physiscore 3.3.0 draws every graph the way Origin does, keeps the manuals on the computer,
shows the state of updates in the main window and tells you what changed after an update.
The analysis is unchanged from 3.1.2; the validation table gives the same values.

### Graphs in the style of Origin
- White graph page with a black 1.5 pt axis box, ticks pointing in on all four sides
  (major 6 pt, minor 3 pt, one minor tick between majors), no grid, Arial, 1.5 pt lines,
  square black-framed legends - in every window, also in the dark theme.
- Series colours follow OriginLab's default increment: black, red, blue, magenta, olive,
  navy, violet, purple, wine, dark cyan. **Settings → Plot colours → Colour-blind safe**
  switches to the Okabe-Ito colours.
- *View → Toggle grid* and the right-click grid toggle are kept across redraws. Exported
  figures (Figure, Report) use the same style.

### Documentation inside the installers
- The user guide, the methods and algorithms, validation, file formats, command line,
  installation notes and the release notes are part of every installer and open offline in
  the browser: **Help** menu, **F1**, *User guide* and *Method notes* in the main window
  (the latter at the tool's own section). `Physiscore --doc METHODS` opens one from the
  command line.
- The self-test of every build checks that the documentation is bundled.

### Updates
- **Updates** tab in the main window: installed version, how this copy was installed,
  whether it can update itself (and why not), automatic-update mode (download and install
  / only tell me / off), last check, latest release seen and the current state
  (checking, downloading, downloaded and verified, up to date), with *Check now*,
  *Install now and restart* (once an update is ready), *What's new* and *Release page*.
- After an update, the first start opens the release notes of the new version.

### Main window
- The tool panel lists, for the selected tool, its input, output, results, default
  settings, references and the section of the method notes; the session settings, updates,
  recent folders and conventions are tabs below it.
