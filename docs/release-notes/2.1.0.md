Physiscore 2.1.0 brings ready-to-run programs for Windows, macOS and Linux and
keeps installed copies up to date by itself. The analysis cores are unchanged
from 2.0.0, so results are identical.

### New
- **Installers for every desktop platform**: Windows installer and portable zip,
  macOS disk images for Apple silicon and Intel, a Debian/Ubuntu `.deb`, and a Linux
  archive with a per-user `install.sh`. Python is not needed.
- **Automatic updates** (⟳ Updates in the toolbar). Once a day the program asks
  GitHub for the latest release; a newer one is downloaded, checked against
  `SHA256SUMS.txt` and installed when you close Physiscore (or right away with
  *Restart now*). Switch to *only tell me* or *off* in the same menu.
- `--selftest`, `--update` and `--version` options for the launcher.

### Changed
- **J-V Curve on macOS and Linux**: without the external Windows `JV_Analysis.exe`,
  the J-V card now opens the built-in J-V analysis window instead of showing
  *EXE not found*. On Windows the external program is still preferred when present.
- An installed copy keeps `physisfera_config.json` (Origin path, optional API key,
  cell area, naming presets) in the per-user settings folder; a file next to the
  program from an older version is copied there once.

Installation guide: [docs/INSTALL.md](https://github.com/jongsu-king/physiscore/blob/main/docs/INSTALL.md).
