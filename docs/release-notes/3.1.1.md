Physiscore 3.1.1 is the first published build of the 3.1.0 feature set. The 3.1.0 tag
was not published because a timing check in the updater's tests failed on the Intel
macOS build machine. In 3.1.1 those tests wait for the update helper to finish its
cleanup. The program itself is the same as 3.1.0.

Compared with 3.0.0, this version adds a cross-technique **Device summary**, reads J-V curves from
CSV and Excel files, matches XRD patterns against reference peak lists, compares many
files side by side, and records every export with a reproducibility side-car. The
analysis cores of 3.0.0 are unchanged, so existing numbers stay the same.

### New
- **Device summary** (new card in the main window). Load the J-V curve and the EQE
  spectrum of one device (optionally the absorbance and PL of the absorber) and get, in
  one table with four plots:
  - Jsc from J-V against the AM1.5G-integrated EQE, with a warning above 5 % mismatch;
  - the band gap from EQE (dEQE/dE), Tauc and the PL peak, their spread and the Stokes shift;
  - Voc against Voc,rad and Voc,SQ, the ΔV1/ΔV2/ΔV3 loss breakdown and the implied EQE_EL;
  - Jsc, FF and PCE as fractions of their Shockley-Queisser values.
- **J-V from CSV, TSV, DAT and Excel**: voltage and current columns are recognised by their
  headers (mA/cm², mA or A). Files without the instrument summary block now get Voc, Jsc,
  FF and PCE from their curve and enter the statistics and box charts.
- **XRD reference matching**: load a peak list (2θ or d, hkl, intensity); reference ticks
  with hkl on the plot, a table of matched reflections with shift and lattice strain, the
  coverage, and the reflections that belong to no reference line (a second phase).
- **XRD Excel export** with peaks, pattern and fit, Williamson-Hall, reference match and
  crystallinity.
- **Compare files** in EQE, Absorbance, PL, XRD, Raman and FTIR: add many files or a folder,
  get one result row per spectrum and a normalised, offset overlay.
- **Side-car files**: each Excel export writes `<name>.analysis.json` with the program
  version, date, input files, every parameter and the main results.
- **Command line**: `device` (the Device summary without the GUI) and `batch` (one table
  for a whole folder).
