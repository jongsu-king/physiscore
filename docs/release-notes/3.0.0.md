Physiscore 3.0.0 is a major upgrade of the analysis cores and of the interface.
Every quantity is now documented with its equation and reference in
[docs/METHODS.md](https://github.com/jongsu-king/physiscore/blob/main/docs/METHODS.md)
and validated against closed-form data in
[docs/VALIDATION.md](https://github.com/jongsu-king/physiscore/blob/main/docs/VALIDATION.md)
(224 tests).

### New analysis
- **J-V**: explicit one-diode model (Lambert W) with a five-parameter fit
  (Jph, J0, n, Rs, Rsh) for every device; forward/reverse sweeps are separated and the
  hysteresis index reported (new *Hysteresis* sheet); Jsc mismatch against EQE.
- **Dark J-V**: full one-diode fit including series resistance (log-space residuals)
  and Cheung dV/dlnJ analysis, next to the sliding-window ideality factor.
- **EQE**: band gap from the derivative distribution (Rau 2017) with edge width,
  automatic Urbach window, J0,rad and Voc,rad with tail extrapolation, Shockley-Queisser
  limits for the derived gap, and the ΔV1/ΔV2/ΔV3 voltage-loss breakdown from a
  measured Voc.
- **Absorbance**: reproducible automatic Tauc region with a standard error of Eg,
  derivative band gap, Urbach energy; any absorbance column of a sheet can be chosen.
- **XRD**: instrument-broadening correction and Scherrer K as inputs, Rachinger Kα2
  stripping, crystallinity index, Williamson-Hall with uncertainties, cubic lattice
  parameter with Nelson-Riley extrapolation, η and R² in the peak table.
- **PL**: energy axis with the Jacobian, single or AIC-selected multi-component
  Gaussian/Voigt fits, energy-domain FWHM (meV), areas and centroids.
- **Raman / FTIR**: arPLS/ALS baselines with controls, Lorentzian/Gaussian band fitting,
  peak-shift tables of every layer against the reference (no network needed), a
  70-entry band library for first assignments, transmittance-to-absorbance.
- **SEM**: D10/D50/D90, coefficient of variation and log-normal parameters with the
  fitted curve drawn over the histogram; statistics sheet in the Excel export.
- **XPS** (auto-fit workspace): Shirley background, charge referencing, doublet
  constraints, region of interest, atomic-concentration dialog with Scofield factors.
- **Command line**: `python physiscore_cli.py jv|dark|eqe|abs|xrd|pl|vib|sem-stats|sq|validate`
  runs the same cores without the GUI and prints JSON with `--json`.

### Interface
- Instrument-style appearance: light theme by default (dark available in Settings),
  menu bars with keyboard shortcuts in every window, plain-text toolbars, a cursor
  read-out in the status bar, compact tables instead of placeholder panels.
- Markdown report export (tables plus a publication-style figure) from every tool.
- The main window lists all ten techniques with what each one derives; Settings holds
  the device area, the Origin path, the optional API key and the appearance.

### Changed
- The Gemini commentary is optional and labelled "Interpretation"; no numerical result
  depends on it.
- Old Windows-only build files were moved to `_legacy/`; the installers for every
  platform are built from `packaging/physiscore.spec`.

Installation guide: [docs/INSTALL.md](https://github.com/jongsu-king/physiscore/blob/main/docs/INSTALL.md).
Installed 2.1.0 copies update themselves to this release.
