Physiscore 3.5.1 corrects a picture in the user guide. The program, its windows and every number it computes are the same as in 3.5.0; no analysis has to be repeated.

### Fixed
- **Picture of the Updates tab.** In the user guide that ships with 3.3.1, 3.4.0 and 3.5.0 the picture of the Updates tab reads "Latest release seen 9.9.9" and "9.9.9 is available". No such release exists. The state came from a local test of the updater on the machine that took the pictures, and the program itself never showed it. The picture now shows a clean state.
- **Method notes, section 6.** The band library holds 74 entries, not 70 as the text said. The library itself is unchanged.

### For people who build the documentation
- `tools/screenshots.py` keeps the updater's settings in the temporary folder of the run, so the pictures do not depend on the machine that takes them.

### Coming from 3.4 or earlier
3.5 added six tools (SCLC, light intensity, TRPL, impedance, C-V and stability), **Open data...**, which recognises a measurement file and opens it in the right tool, and the Workspace and Results tabs. The full list is in the notes of 3.5.0: https://github.com/jongsu-king/physiscore/releases/tag/v3.5.0

### Install or update
Installed copies offer this version in the Updates tab (or download it with your setting). Otherwise download the file for your system below; SHA256SUMS.txt lists the checksums.
